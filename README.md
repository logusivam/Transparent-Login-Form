## Project Overview & Key Features
* Modern user interface design featuring frosted-glass transparency (glassmorphism) via CSS backdrop filters.
* Immersive 3D background rendering powered by Three.js to elevate standard form aesthetics.
* Production-ready validation for standard email and password credential input fields.
* Integrated secure Google OAuth authentication workflows.
* Responsive, multi-panel layout transitions powered by Swiper and styled with premium typography.

## Tech Stack
* **Frontend UI:** HTML5, CSS3 (Glassmorphism), Vanilla JavaScript, Varnish
* **3D Graphics:** Three.js (WebGL)
* **Backend & Auth:** Firebase Authentication (Email/Password & Google OAuth)
* **Assets & Typography:** Google Fonts, Font Awesome

## Getting Started

### Prerequisites
* A modern web browser supporting WebGL and advanced CSS backdrop-filter properties.
* A Firebase Project instance to connect authentication services.

### Installation
```bash
npm install firebase
```

### Usage
```bash
npm run dev
```
